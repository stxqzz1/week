# Week — личный план (PWA)

## Запуск
PWA требует HTTPS или localhost, поэтому просто открыть `index.html` двойным кликом недостаточно для установки и офлайн-режима.

### Самый быстрый способ
1. Распакуй архив.
2. Залей содержимое папки на GitHub.
3. Включи GitHub Pages в Settings → Pages → Deploy from branch.
4. Открой получившуюся HTTPS-ссылку на телефоне или ПК.
5. В браузере выбери «Установить приложение» / «Добавить на главный экран».

Также можно запустить локально командой `python -m http.server 8000` и открыть `http://localhost:8000`.

## Возможности
- Расписание на все 7 дней.
- Переключение между днями недели.
- Отметки выполненных задач сохраняются в браузере.
- Отдельный прогресс для каждой календарной даты.
- Офлайн-кэш после первого открытия по HTTPS/localhost.

Данные хранятся локально в браузере и не синхронизируются между устройствами.
